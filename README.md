# Project Template

This project template is designed as a base repository for any project. It includes a basic structure for a project to be customized and built upon. For starters, this readme should be updated with pertinent information for the project.

## Creating a README

- The contents of this readme should be updated with information about the project.
- See [Make a README](https://www.makeareadme.com/) for tips on creating a good README, and specifically [what to include](https://www.makeareadme.com/#suggestions-for-a-good-readme).

## Quick links

- [Setup Guide](docs/setup-guide.md): Instructions for setting up the project for the first time.
- [Quickstart Guide](docs/quickstart-guide.md): Instructions for making changes to the project after initial setup.
- Sub-directory READMEs: Additional information for how to use specific directories in the project can be found in the READMEs of those directories.
